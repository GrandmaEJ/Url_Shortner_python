🛠️ API Usage Examples

Single URL (POST)

curl -X POST http://localhost:8398/api/short \
-H "Content-Type: application/json" \
-d '{"url": "https://example.com", "custom_id": "example"}'

Single URL (GET)

GET http://localhost:8398/api/short?url=https://example.com&custom_id=example

Bulk URLs

curl -X POST http://localhost:8398/api/urls/bulk \
-H "Content-Type: application/json" \
-d '{"urls": ["https://example.com", "https://google.com"]}'

Analytics

GET http://localhost:8398/api/urls/abc123/analytics
